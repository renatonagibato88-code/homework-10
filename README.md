# Лабораторная работа 8

## Вариант 20. Сумма гармонического ряда

### Постановка задачи

Вычислить вещественное значение для заданного целого \(N\), заданного пользователем:
1 + 1/2 + 1/3 + ... + 1/N
Для вычисления необходимо использовать цикл for.
### Программа

Программа получает от пользователя значение N.

На каждом шаге цикла вычисляется новое слагаемое и добавляется к сумме:

sum = sum + 1.0 / i

После выполнения N повторений программа выводит итоговую сумму.
