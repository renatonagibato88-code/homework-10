# Лабораторная работа

## Вариант 20. Трапеция.

### Постановка задачи

Необходимо разработать программу для работы с трапецией.

Пользователь задаёт стороны `a`, `b` и высоту `h`.

Программа должна выбрать меню выбора одной из операций:

1. Рассчитать площадь фигуры.
2. Вывести определение фигуры.
3. Нарисовать фигуру символом `*`.

Для каждой операции используется специальная функция.

### Площадь фигуры

Площадь трапеции рассчитывается по формуле:

S = (a + b)^2 / 2

**где:**

* `a` — нижнее основание трапеции;
* `b` — верхнее основание трапеции;
* `h` — высота трапеции.

### Определение фигуры

Трапеция — это четырехугольник, у которого две стороны параллельны (основания), а две другие стороны не параллельны (боковые стороны).

### Рисование фигур

Трапеция выводится в символическую консоль `*`.

По условию обслуживания необходимо вывести только контурные данные.

Пример для `a = 9`, `b = 5`, `h = 3`:

```text
 ***** 
 *   *
*********
```
